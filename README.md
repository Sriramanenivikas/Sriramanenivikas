## Intelligent Warehouse Orchestration System (IWOS)

<img src="https://readme-typing-svg.demolab.com?font=Press+Start+2P&size=8&duration=1&pause=1000&color=888888&vCenter=true&repeat=false&width=450&height=80&lines=Enterprise-grade+cloud-native;microservices+platform+for;warehouse+operations+at+scale"/>

Scalable cloud-native microservices platform for large-scale warehouse operations focused on high availability, real-time data processing, and event-driven architecture.

Handles 1000+ concurrent warehouse operations using Kafka-based event streaming, RabbitMQ task queues, Redis caching, and Kong Gateway for secure API routing. Includes AI-powered analytics and demand forecasting using Python. Deployed on AWS with Docker and CI/CD pipelines for zero-downtime scaling.

`Java` `Python` `Spring Boot` `Kafka` `RabbitMQ` `PostgreSQL` `MongoDB` `Redis` `Docker` `AWS` `React`

## CareSync — Hospital Automation System

<img src="https://readme-typing-svg.demolab.com?font=Press+Start+2P&size=8&duration=1&pause=1000&color=888888&vCenter=true&repeat=false&width=450&height=80&lines=Full-stack+hospital+management;with+role-based+access+control;reducing+admin+tasks+by+70%25"/>

Full-stack hospital management platform to automate clinical, administrative, and patient-facing workflows with secure role-based access control.

`Java` `Spring Boot` `Spring Security` `JWT` `PostgreSQL` `React` `Tailwind CSS`

Implements JWT-secured authentication for 5 roles (Admin, Doctor, Nurse, Patient, Receptionist), normalized PostgreSQL schema with optimized indexing, and REST-based service architecture. Improves hospital efficiency and reduces manual administrative effort.
